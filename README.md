Team Retrospective Analysis

The main challenge our team faced was ensuring a consistent responsive design and seamless integration between multiple sections of the website. Different development environments and screen sizes caused layout inconsistencies, which we resolved by adopting a standardized CSS structure and regular design reviews.

A notable merge conflict occurred in the index.html file during simultaneous updates to the team and navigation sections. The issue was resolved collaboratively by reviewing both contributions, merging the best elements, and validating the outcome through local testing.

Our pull request and peer review workflow significantly improved our efficiency and final quality. Each member worked on dedicated branches, submitted pull requests for review, and received constructive feedback before merging. This process encouraged collaboration, minimized errors, and ensured a cohesive and professional final portfolio.
